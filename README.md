# 🗺️ 언어/분야별 IDE(통합 개발 환경) 추천 지도

작성자님의 다양한 개발 스펙트럼(웹, AI, 하드웨어, 게임 등)을 완벽하게 커버할 수 있는 **언어/분야별 IDE 추천 지도**입니다. 실무 및 글로벌 개발 생태계의 표준(De facto standard)을 기준으로 작성되었습니다.

---

## 🌐 1. 웹 개발 & 백엔드 (Web & Backend)

| 언어 / 프레임워크 | 🏆 1순위 추천 (국룰) | 🥈 2순위 (대안) | 추천 이유 및 실무 팁 |
| :--- | :--- | :--- | :--- |
| **Java / Spring Boot** | **IntelliJ IDEA** | Eclipse | 스프링 생태계와의 궁합이 압도적입니다. 단, 과거에 이클립스로 작성한 순수 Java(Swing 등) 코드는 이클립스로 유지하는 것이 안전합니다. |
| **HTML, CSS, JS, TS** | **VS Code** | WebStorm | 프론트엔드 생태계를 천하통일한 가볍고 강력한 에디터입니다. 수많은 확장 프로그램(Extension) 지원이 장점입니다. |

## 🤖 2. 데이터 과학 & AI & 봇 (Data, AI & Automation)

| 분야 / 용도 | 🏆 1순위 추천 (국룰) | 🥈 2순위 (대안) | 추천 이유 및 실무 팁 |
| :--- | :--- | :--- | :--- |
| **Python (AI, 백테스팅)** | **JupyterLab** / Colab | VS Code (Jupyter) | 코드를 한 줄씩 실행하며 데이터의 흐름과 그래프를 즉각적으로 확인해야 하는 연구/분석용으로 최적화되어 있습니다. |
| **Python (매매 봇, 서버)** | **PyCharm** | VS Code | 코드가 길어지고 모듈 간 연결이 복잡해지는 무거운 파이썬 프로젝트에서 디버깅과 자동완성 성능이 가장 뛰어납니다. |
| **Python (단순 스크립트)** | **VS Code** | IDLE | 매크로나 가벼운 파일 편집기 같은 단일 스크립트를 작성할 때는 무거운 IDE 대신 가벼운 VS Code가 가장 빠릅니다. |

## 🎮 3. 게임 개발 (Game Development)

| 엔진 / 언어 | 🏆 1순위 추천 (국룰) | 🥈 2순위 (대안) | 추천 이유 및 실무 팁 |
| :--- | :--- | :--- | :--- |
| **Unity (C#)** | **Visual Studio** | **JetBrains Rider** | 윈도우 환경 기본값은 VS입니다. 하지만 코드 성능 분석과 쾌적함 면에서 프로들은 유료 툴인 **Rider**를 매우 선호합니다. |
| **Unreal (C++)** | **Visual Studio** | JetBrains Rider | 언리얼 엔진 자체의 구조가 Visual Studio에 고도로 묶여 있어 가장 안정적이고 무난한 선택지입니다. |

## 📱 4. 모바일 앱 & 🔌 하드웨어 (Mobile & Embedded)

| 플랫폼 / 언어 | 🏆 1순위 추천 (국룰) | 🥈 2순위 (대안) | 추천 이유 및 실무 팁 |
| :--- | :--- | :--- | :--- |
| **Android (Kotlin/Java)**| **Android Studio** | IntelliJ IDEA | 구글 공식 지원 툴이므로 안드로이드 네이티브 앱 개발은 사실상 다른 선택지가 없습니다. |
| **iOS (Swift)** | **Xcode** | - | 애플 기기용 앱 개발을 위해서는 맥(Mac) 환경과 Xcode가 강제됩니다. |
| **Arduino (C/C++)** | **Arduino IDE 2.x**| **VS Code (PlatformIO)**| 단순 센서 테스트는 기본 IDE가 좋으나, 통신 모듈 등 코드가 복잡해지면 **VS Code + PlatformIO** 조합이 훨씬 쾌적합니다. |

## 🛠️ 5. 범용 / 시스템 프로그래밍 (General & System)

| 언어 / 용도 | 🏆 1순위 추천 (국룰) | 🥈 2순위 (대안) | 추천 이유 및 실무 팁 |
| :--- | :--- | :--- | :--- |
| **C / C++ (데스크톱 앱)** | **Visual Studio** | CLion / VS Code | 윈도우 환경에서 C++을 컴파일하여 단독 실행 파일(`.exe`)을 뽑아낼 때, VS의 컴파일러(MSVC)와 디버거는 대체 불가 수준입니다. |

---

### 💡 프로 개발자를 위한 추가 꿀팁 (요약)
* **JetBrains Rider 도입 고려:** 유니티나 언리얼 작업을 많이 하신다면 비주얼 스튜디오 대신 Rider를 한 번쯤 경험해 보시는 것을 추천합니다. 무거운 C++/C# 자동완성을 훨씬 빠르고 가볍게 처리해 줍니다.
* **하드웨어 코딩의 신세계, PlatformIO:** 기본 아두이노 IDE의 빈약한 자동완성에 지치셨다면, VS Code의 확장 프로그램인 `PlatformIO`를 설치해 보세요. 수백 가지 하드웨어 보드를 VS Code의 강력한 환경에서 그대로 코딩할 수 있습니다.
